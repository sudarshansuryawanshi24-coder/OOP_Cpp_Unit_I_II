## About the Repository

This repository contains the Unit II C++ programming practicals based on the provided **OOP with C++ Unit 2 Inheritance Practical Code Book**.

## List of Programs

| No. | Program | Description |
|---:|---|---|
| 01 | Basic Single Inheritance | Demonstrates inheritance using Person and Student. |
| 02 | Protected Member Access | Demonstrates access to a protected base-class member from a derived class. |
| 03 | Public vs Private Inheritance | Demonstrates accessibility differences between public and private inheritance. |
| 04 | Multilevel Inheritance | Demonstrates Person → Employee → Manager inheritance. |
| 05 | Hierarchical Inheritance | Demonstrates multiple derived classes using Vehicle as a common base class. |
| 06 | Multiple Inheritance | Combines academic and sports records using two base classes. |
| 07 | Multiple-Inheritance Ambiguity | Resolves same-named base-class functions using scope resolution. |
| 08 | Constructor and Destructor Order | Demonstrates object construction and destruction order. |
| 09 | Parameterized Base Constructor | Initializes a base class through a derived-class constructor. |
| 10 | Function Overriding | Demonstrates virtual functions and overriding in derived classes. |
| 11 | Abstract Class | Demonstrates a pure virtual function and abstract base class. |
| 12 | Virtual Base Class and Diamond Inheritance | Uses virtual inheritance to avoid duplicate base-class data. |
| 13 | Friend Class | Demonstrates access to private data through a friend class. |
| 14 | Nested Class | Demonstrates a class declared inside another class. |
| 15 | Vehicle Rental System | Mini-project using inheritance and function overriding. |
| 16 | Employee Payroll System | Mini-project using an abstract class, inheritance and overriding. |

## Compilation

Each program can be compiled with a C++ compiler such as g++:

```bash
g++ Program_01/Basic_Single_Inheritance.cpp -o program01
./program01
```

Repeat the same process for the other programs.
